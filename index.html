삼성전자, 애플, 엔비디아 3종 자산에 대한 시계열 탐색과 효율적 투자선 분석 결과를 한 눈에 확인하세요.

효율적 투자선으로 이동

데이터 개요

원본: temp.csv — 복수 티커를 포함한 3중 헤더 구조의 일별 시세 데이터셋입니다.

  • 추적 자산: 삼성전자(005930.KS), 애플(AAPL), 엔비디아(NVDA)
  • 수록 지표: 종가, 고가, 저가, 시가, 거래량
  • 관측 기간: 2022년 1월 3일 – 2023년 12월 29일 (거래일 기준)
데이터 요약 자세히 보기

분석 워크플로

두 개의 파이썬 스크립트가 전체 분석을 자동화합니다. 표준 라이브러리만을 사용하므로 별도 패키지 설치가 필요 없습니다.

  1. scripts/summarize_temp.py: 데이터 구조를 파악하고 일별 수익률, 거래량, 가격 통계를 요약합니다.
  2. scripts/efficient_frontier.py: 연율화 및 무위험 수익률 가정에 따라 효율적 투자선과 최대 샤프 비율 조합을 도출합니다.

터미널에서 python scripts/summarize_temp.py --csv temp.csv, python scripts/efficient_frontier.py --csv temp.csv --output assets/efficient_frontier.svg 명령으로 재현할 수 있습니다.

효율적 투자선 시각화

효율적 투자선은 주어진 위험 수준에서 기대 수익률이 최대가 되는 포트폴리오 조합을 의미합니다. 아래 SVG는 무위험 수익률 3%와 연율화 252 거래일 가정 하에 계산된 결과입니다.

주요 포인트

  • 파란 점: 단일 자산 포트폴리오 (삼성전자, 애플, 엔비디아)
  • 주황색 별: 최대 샤프 비율 포트폴리오
  • 검은 선: 위험 대비 기대 수익률이 우수한 효율적 투자선

추가 산출물

데이터와 분석 결과는 다음 문서로 정리되어 있습니다.

  • README.md — 데이터 구조와 통계 테이블, 실행 가이드
  • efficient_frontier.svg — SVG 형식의 효율적 투자선 그래프
